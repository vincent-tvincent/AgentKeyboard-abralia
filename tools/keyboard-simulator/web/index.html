A workspace for keyboard interactions

Click keys to use their current actions. Double-click the mode key to enter Agent Mode; hold it to navigate. Hold an empty F-key to close a gap. The knob controls are below the board.

Use Test agents to send notifications or change state. Use Design JSON to import a timeline or LED frames, then replay it. The simulator uses the host controller and renderer; it does not connect to your keyboard or open agent conversations.
